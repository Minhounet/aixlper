# Yells: Harinezumi-bengoshi's banners

Read this at the first yell of a session (the rule, its moments and its off
switch are in `SKILL.md`, "Yells"). Copy the banner for the moment
**verbatim**, inside a code block so it stays monospaced. Never redraw it,
never resize it: a hand-drawn copy loses the finger. Then the one-line case
under it, as shown.

Harinezumi-bengoshi (針鼠弁護士, the hedgehog lawyer) is this repo's own
character. The catchphrases come from courtroom games; the drawing does not,
and must not become any game's character.
