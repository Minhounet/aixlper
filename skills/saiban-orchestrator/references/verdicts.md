# Verdicts: Tanuki-saibankan's banners

Read this at the verdict (the rule, what decides it and the off switch are in
`SKILL.md`, "Court"). Copy the banner **verbatim**, inside a code block so it
stays monospaced. Never redraw it, never resize it: a hand-drawn copy loses
the tanuki. Then the case lines under it, as shown.

Tanuki-saibankan (狸裁判官, the tanuki judge) is this repo's own character,
the judge facing Harinezumi-bengoshi (`yells.md`). What makes it a tanuki and
must stay: the leaf on its head (the folklore tanuki's), the round ears, the
dark mask around the eyes, the striped tail and the round belly. The gavel
makes it the judge.

## NOT GUILTY!

Every AC or step verified or waived, the last test run green, no blocking
finding or discrepancy open, the work committed. It smiles; the gavel rests.
